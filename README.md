# ShadowCosmos

ShadowCosmos is a custom MediaWiki skin designed for Shadowrun wikis. It features a dark, cyberpunk-themed aesthetic with neon accents and integrated Ko-fi support.

## Features

- Dark cyberpunk theme with neon pink and cyan accents
- Responsive design that works on mobile and desktop
- Integrated Ko-fi support button in the footer
- Optimized for Shadowrun content
- Compatible with MediaWiki 1.35 and above (including 1.43)

## Installation

1. Download and place this skin in your `skins/` directory.
2. Add the following line to your `LocalSettings.php`:

```php
wfLoadSkin( 'ShadowCosmos' );
